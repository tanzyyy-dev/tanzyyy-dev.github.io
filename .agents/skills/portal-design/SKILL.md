# Webデザイン作業指針

Webサイトのデザイン作業では、以下の公開Skillを読み、
AI Slopを防ぐための指針を適用する。

https://github.com/anthropics/skills/blob/main/skills/frontend-design/SKILL.md

参照できない場合は、適用したと偽らず、その旨を報告する。

## コンセプトカラー

サイトのコンセプトカラーは、**ミニチュアシュナウザーの毛色「ソルト＆ペッパー」**に由来する次の4色。

| 色名 | HEX | 主な用途の目安 |
| --- | --- | --- |
| チャコール | `#292B2D` | 主要な文字、濃色の背景 |
| グレー | `#777A7B` | 補助的な文字、落ち着いたアクセント |
| シルバー | `#B7B9B6` | 境界線、控えめな面 |
| オフホワイト | `#F0EFEB` | 明るい背景、余白の基調 |

- サイト全体の色使いはこの4色を中心に組み立て、一貫した印象を保つ。
- **4色以外の使用は禁止しない。** 視認性、アクセシビリティ、作品固有の表現、状態表示などに必要なら追加色を使ってよい。
- 4色をすべて均等に使う必要はない。各画面の情報設計やコントラストに合わせて配分する。

## 不自然な改行を生む幅制限の禁止

- 短い説明文や紹介文を、慣習的な `max-width`、`ch` 単位、狭い固定幅のコンテナで機械的に制限しない。
- 画面に十分な横幅があるのに、文章が不自然な位置で折り返されるレイアウトを禁止する。
- テキストの幅は実際の文量と周囲の配置に合わせて決める。読みやすさを理由にした一律の狭幅指定はしない。
- PC とスマートフォンの両方で、日本語・英語それぞれの改行位置を考慮する。

## X 関連UI

- X 関連の機能を設計・実装する際は、まず [X Publish の無料機能](../x-publish/SKILL.md) を参照する。
- X API の有料利用を前提とせず、公式の無料埋め込み・ボタンを目的に応じて有効活用する。
- 公式ウィジェットを置くこと自体を目的にしない。ページの情報設計と見た目に合う機能だけを選び、読み込み失敗時もリンクで利用できるようにする。
